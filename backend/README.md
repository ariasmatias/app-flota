# Backend

Espacio para API, servicios, modelos, validaciones, permisos y auditoría. El código irá en src/. Se prioriza JavaScript; el framework aún no se ha elegido.

Las integraciones externas se consumirán mediante adaptadores de integrations/. El servidor corporativo y sus conexiones no deben ser requisitos para desarrollar con datos ficticios. No hay todavía API ejecutable.
