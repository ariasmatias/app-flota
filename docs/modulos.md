# Módulos propuestos

Alcance inicial sujeto a validación con el equipo y los usuarios.

| Módulo | Propósito |
| --- | --- |
| Inicio | Menú, accesos y resumen |
| Vehículos | Registro, consulta y estado de unidades |
| Conductores | Referencias y asignaciones |
| Usuarios y permisos | Roles y autorización funcional |
| Talleres | Datos y participación en mantenimiento |
| Órdenes de trabajo | Registro, seguimiento y estados |
| Documentación y adjuntos | Archivos y vencimientos |
| Reportes | Consultas y resúmenes |
| Historial y auditoría | Trazabilidad de operaciones |

## Primeras tareas

1. Validar módulos, roles y operaciones.
2. Prototipar menú e interfaz con datos ficticios.
3. Definir entidades y relaciones.
4. Acordar contratos de API y framework de backend.
5. Implementar un primer flujo de vehículos de extremo a extremo.

Los permisos y reglas de transición entre estados deben documentarse antes de implementar cada flujo.
